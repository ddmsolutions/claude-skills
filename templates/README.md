# Templates

> Built 27 Aug 2026 from the Clief Notes distillations (memories #339-368), the Vault
> Toolkit and the ICM paper. Copy out, replace [brackets], delete unused sections.
> Each template embodies its own rules: routing stays on one screen, contracts carry
> must-not lists, context files describe the work not the AI.

| Template | Use when |
|----------|----------|
| `claude-md.md` | Starting any new workspace or project (Layer 0 routing file) |
| `stage-context.md` | Defining one stage of a pipeline (Layer 2 contract) |
| `prd.md` | Before any build: scope it, checkpoint it, then code |
| `progress.md` | Ending a session mid-task; the next session reads this first |
| `constraints.md` | The never-do list; loads with every writing or build task |
| `automation-audit.md` | Before automating any workflow; scores impact and risk, sets gates |

House rules baked into all of them: plain senior British English, no en or em dashes,
evidence over adjectives, one fact in one location, and a Last updated line on
anything that can go stale.
